Envoyez les PDF ouverts dans Chrome directement à votre serveur Paperless-ngx. Vous pouvez par exemple classer une facture depuis votre espace client pendant qu’elle est encore ouverte dans le navigateur.

Ouvrez Paperless Upload depuis la barre d’outils de Chrome pour envoyer le PDF affiché. Vous pouvez aussi envoyer en une fois tous les PDF détectés dans les onglets de la fenêtre active. Pour les fichiers sur votre appareil, utilisez le sélecteur de fichiers ou glissez les PDF dans la fenêtre de l’extension.

Pour la première connexion, indiquez l’adresse de votre serveur Paperless et votre jeton d’API. Chaque envoi se fait à votre demande. Une fois les fichiers prêts, vous pouvez fermer la fenêtre de l’extension. Le transfert se poursuit tant que Chrome reste ouvert.

L’extension indique quand Paperless a accepté un fichier pour le traiter. Si le statut de l’importation est disponible, elle affiche le résultat. Une fois l’importation terminée avec succès, vous pouvez ouvrir le document dans Paperless. En l’absence de confirmation, vérifiez d’abord votre boîte de réception Paperless. Le fichier n’est jamais renvoyé automatiquement.

L’interface utilise la langue de Chrome et est disponible en dix langues. Les réglages et les fichiers temporaires restent dans votre profil Chrome. Les PDF sélectionnés sont envoyés directement au serveur configuré. L’extension ne contient ni publicité ni outil de suivi.

Nécessite Chrome 116 ou une version ultérieure. À partir de Chrome 157, l’extension peut reprendre un PDF déjà chargé dans un onglet, même si sa consultation nécessite une connexion. Si un PDF est inaccessible, enregistrez-le depuis la visionneuse, puis sélectionnez le fichier. L’envoi direct depuis un onglet affichant un PDF local nécessite une autorisation supplémentaire dans Chrome.

Paperless Upload est un projet indépendant de Paperless-ngx et n’est pas un produit officiel.
